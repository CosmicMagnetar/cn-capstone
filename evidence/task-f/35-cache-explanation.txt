Cache-Control: max-age=60 means the client can treat the response as fresh for 60 seconds and reuse the cached response during that time. After 60 seconds, the cached response becomes stale and the client must request or revalidate the resource. The ETag identifies the current version of the resource and can be used with If-None-Match. If the resource has not changed, the server can return 304 Not Modified instead of sending the full response body.
